# Lien avec d’autres standards
Ce géostandard concerne l’eau et l’assainissement et ne prévoit pas de standardiser d’autres types de réseaux.

Ainsi pour les usages annexes, par exemple les réseaux électriques, permettant le fonctionnement des réseaux d’eau et d’assainissement, il est possible de se diriger vers le standard StaR-Elec ([https://cnig.gouv.fr/gt-star-elec-a23975.html](https://cnig.gouv.fr/gt-star-elec-a23975.html)).

Les points d’eau incendie font, eux aussi, l’objet d’une standardisation nationale ([https://schema.data.gouv.fr/datakode/schema-pei/1.0.1/](https://schema.data.gouv.fr/datakode/schema-pei/1.0.1/)) qui est reprise par ce géostandard pour mémoire.
